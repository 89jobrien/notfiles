# Plan: notfiles v0.2 — Public Release Quality

## Goal

Make notfiles production-ready for managing real dotfiles repos (starting
with `~/dotfiles/`) and prepare the crate for public release on crates.io.
15 improvements across config, library API, features, and polish.

## Architecture

### Crates affected

| Crate | Changes |
|-------|---------|
| `notcore` | Config model (include/exclude, platform), error cleanup, Reporter trait |
| `notfiles` | CLI (new subcommands, --json), linker (LinkResult), InMemoryFileStore |
| (workspace) | Cargo.toml metadata, rustqual config |

### New types and traits

| Type/Trait | Crate | Location |
|-----------|-------|----------|
| `PackageFilter` | `notcore` | `src/config.rs` |
| `Platform` | `notcore` | `src/config.rs` |
| `Reporter` | `notcore` | `src/reporter.rs` (new) |
| `TerminalReporter` | `notfiles` | `src/adapters/reporter.rs` (new) |
| `JsonReporter` | `notfiles` | `src/adapters/reporter.rs` |
| `LinkResult` | `notfiles` | `src/linker.rs` |
| `InMemoryFileStore` | `notfiles` | `src/adapters/memory.rs` (new) |

### Data flow (link command)

```text
CLI parse → Config::load (with filter + platform)
  → discover_packages (filtered by include/exclude + platform)
  → link_package (returns LinkResult per package)
  → Reporter.report_link(results)
  → State.save
```

### Unchanged crates

`notsecrets`, `nothooks`, `notnet`, `notstrap`, `notgraph` — no changes
in this plan. notstrap will benefit automatically from notcore/notfiles
API improvements.

## Tech Stack

- Rust 2024 edition (already set)
- New dependency: `clap_complete = "4"` (shell completions)
- New dependency: `serde_json = "1"` (--json output)
- New dependency: `strsim = "0.11"` (fuzzy matching for config validation)
- All other deps already in workspace

## Out of Scope

- Template/variable substitution (`.tmpl` files) — separate crate if pursued
- Windows support — unix-only, clean error on other platforms
- Stow compatibility — no `.stow-local-ignore`, no `--stow-compat` flag
- Changes to notsecrets, nothooks, notnet, notstrap, notgraph

   pub fn included_packages(&self) -> Option<Vec<&str>> {
       if self.defaults.include.is_empty() {
           None
       } else {
           let mut v: Vec<&str> =
               self.defaults.include.iter().map(|s| s.as_str()).collect();
           v.sort();
           Some(v)
       }
   }

   /// Returns true if this package name appears in the exclude list.
   pub fn is_package_excluded(&self, name: &str) -> bool {
       self.defaults.exclude.iter().any(|e| e == name)

       {
           return Err(NotfilesError::Config(
               "include and exclude are mutually exclusive".into(),

       }
       Ok(())
   }

   /// Events emitted during link/unlink/status operations.
   #[derive(Debug, Clone)]
   pub enum LinkEvent<'a> {
       Link {
           source: &'a str,
           target: &'a Path,
       },
       Copy {
           source: &'a str,
           target: &'a Path,
       },
       Skip {
           source: &'a str,
           reason: &'a str,
       },
       Backup {
           from: &'a Path,
           to: &'a Path,
       },
       Remove {
           target: &'a Path,
       },
       CreateDir {
           path: &'a Path,
       },
       DryRun {
           action: &'a str,
           source: &'a str,
           target: &'a Path,
       },
   }

   /// Port for reporting link/unlink progress. Library code calls this
   /// instead of println!.
   pub trait Reporter {
       fn report(&self, event: &LinkEvent<'_>);
   }

   /// No-op reporter for when output is unwanted (library consumers,
   /// non-verbose mode).
   pub struct SilentReporter;

   impl Reporter for SilentReporter {
       fn report(&self, _event: &LinkEvent<'_>) {}
   }

   ```rust
   pub fn adopt_files(
       dotfiles_dir: &Path,
       config: &Config,
       state: &mut State,
       package: &str,
       files: &[String],
       opts: &LinkOptions,
       fs: &dyn FileStore,
       reporter: &dyn Reporter,
   ) -> Result<usize, NotfilesError> {
       let target_base = expand_tilde(config.target_for(package))?;
       let package_dir = dotfiles_dir.join(package);
       let mut adopted = 0;

       for file in files {
           let target = target_base.join(file);
           let source = package_dir.join(file);

           if !fs.exists(&target) {
               return Err(NotfilesError::Other(
                   format!("{} does not exist", target.display()),
               ));
           }
           if fs.exists(&source) {
               return Err(NotfilesError::Conflict {
                   path: source,
                   reason: "already exists in package".into(),
               });
           }

           // Create parent dirs in package
           if let Some(parent) = source.parent().filter(|p| !fs.exists(p)) {
               fs.create_dir_all(parent)?;
           }

           if opts.dry_run {
               reporter.report(&LinkEvent::DryRun {
                   action: "adopt",
                   source: file,
                   target: &target,
               });
               continue;
           }

           // Move target -> source (into package)
           fs.rename(&target, &source)?;
           // Symlink target -> source
           #[cfg(unix)]
           fs.symlink(&source, &target)?;

           state.add_entry(StateEntry {
               package: package.to_string(),
               source: source.to_string_lossy().to_string(),
               target: target.to_string_lossy().to_string(),
               method: Method::Symlink,
               linked_at: chrono::Utc::now().to_rfc3339(),
           });
           adopted += 1;
       }

       if !opts.dry_run {
           state.save(dotfiles_dir, fs)?;
       }
       Ok(adopted)
   }
   ```

   /// Suggest the closest package name if the user made a typo.
   /// Returns None if no close match (distance > 2).
   pub fn suggest_package<'a>(
       name: &str,
       available: &[&'a str],
   ) -> Option<&'a str> {
       available
           .iter()
           .filter_map(|candidate| {
               let dist = strsim::damerau_levenshtein(name, candidate);
               if dist <= 2 { Some((*candidate, dist)) } else { None }
           })
           .min_by_key(|(_, d)| *d)
           .map(|(name, _)| name)
   }

   use std::cell::RefCell;
   use std::collections::{HashMap, HashSet};
   use std::path::{Path, PathBuf};

   use crate::ports::FileStore;

   /// In-memory file system for testing. Not thread-safe.
   pub struct InMemoryFileStore {
       files: RefCell<HashMap<PathBuf, Vec<u8>>>,
       dirs: RefCell<HashSet<PathBuf>>,
       symlinks: RefCell<HashMap<PathBuf, PathBuf>>,
   }

   impl InMemoryFileStore {
       pub fn new() -> Self {
           Self {
               files: RefCell::new(HashMap::new()),
               dirs: RefCell::new(HashSet::new()),
               symlinks: RefCell::new(HashMap::new()),
           }
       }

       pub fn add_file(&self, path: impl AsRef<Path>, content: &[u8]) {
           self.files
               .borrow_mut()
               .insert(path.as_ref().to_path_buf(), content.to_vec());

           self.dirs
